# Security

Report vulnerabilities privately using GitHub's **Report a vulnerability**
button on this repository's Security tab. Do not include private document source
in public issues.

The SDK executes source in a dedicated worker by default. File admission limits
and worker timeouts are not a process memory sandbox. Hosts must authorize
project, package and font bytes. The optional HTML preview uses a scriptless,
opaque-origin iframe and a restrictive content policy; raw exported HTML is an
artifact and must not be injected into an application's trusted DOM.

The current development line is 0.2.x. Compatibility and qualification limits are
recorded in docs/architecture.md and docs/qualification.md.
